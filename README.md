# 🎨 CPP4_3DViewer_v2.0  

**CPP4_3DViewer_v2.0** — это учебный проект на **C++17**, реализующий программу для просмотра 3D-моделей в каркасном виде.  

Приложение построено по принципам **ООП** и паттерну **MVC**, поддерживает аффинные преобразования (перемещение, поворот, масштабирование) и предоставляет удобный графический интерфейс на базе **Qt**.  

> 🧩 Цель проекта — реализовать собственный инструмент визуализации 3D-моделей, познакомиться с архитектурными паттернами и закрепить работу с GUI и графикой.

## 🛠 Технологии  

- **C++17** — основной язык разработки  
- **Qt** — графический интерфейс  
- **CMake** — система сборки  
- **GTest** — модульное тестирование  
- **Паттерны проектирования** — MVC, Фасад, Стратегия, Команда  
- Пространство имён: `s21`  

---

## 🚀 Функциональность  

### 📂 Работа с моделями  

- Загрузка каркасных моделей из `.obj` файлов  
- Поддержка моделей до **1 000 000 вершин** без зависаний  
- Отображение информации о модели (название, количество вершин и рёбер)  

### 🧭 Аффинные преобразования  

- Перемещение вдоль осей **X, Y, Z**  
- Поворот вокруг осей **X, Y, Z**  
- Масштабирование  

### 🎛 GUI  

- Кнопка выбора файла  
- Зона визуализации модели  
- Поля ввода и кнопки для трансформаций  
- Панель информации о модели
